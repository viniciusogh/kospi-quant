# 시장 흐름 요약 합의

사용자는 종목별 보고서를 전부 읽지 않으며 종합추천의 소수 종목만 상세히 검토한다. 나머지 보고서는 시장 흐름을 이해하는 자료로 활용하고 보존한다.

## 확정한 표시 방향

- 앞에는 업종·테마 단위 시장 흐름 요약과 종합추천을 둔다.
- 기존 후보 10개 상세 레포트는 `전체 종목 자료` 토글 하나에 모은다.
- 주가는 최근 5일·20일 수익률 숫자로만 표시한다. 주가 선그래프는 넣지 않는다.
- 수급은 최근 5거래일의 외국인·기관 순매수 금액을 날짜별로 합산하여 업종당 작은 막대그래프 하나로 표시한다. 사용자 후속 결정으로 외국인/기관 분리 그래프를 대체하고 그래프 크기도 줄인다. 합산값이 음수면 순매도다.
- 뉴스와 배경 설명은 넣지 않는다.
- 사용자 후속 승인: 수급 그래프 아래에 주가와 수급을 연결한 해석을 1~2문장 붙인다. 숫자를 반복하거나 뉴스·상승 원인을 덧붙이지 않는다. 기간별 수익률과 합산 수급이 보여주는 동행/엇갈림을 설명한다. 합산값으로 외국인과 기관 각각의 매매 방향을 단정하지 않는다.
- 상승 종목 수는 해석에 활용하되 `8개 중 6개, 직전 5일은 2개` 같은 숫자 나열을 본문에 표시하지 않는다.
- 한 줄 설명에는 실제 변화를 쉽게 표현한다. 추상적인 `새로 강해지기 시작한 분야` 같은 분류명 대신 업종 이름과 변화가 드러나야 한다.
- 강해지는 분야와 약해지는 분야를 함께 요약한다.
- 한 줄 판단은 최근 5거래일 변화에 무게를 둔다. 최근 20일이 상승해도 최근 5일이 하락했다면 최근 약화를 설명하고 20일 수익률을 함께 보여준다.

## 구현 전 확인

기존 자료에는 업종 평균 수익률, 합산 수급, 일별 이력이 있다. 종목별 상승 확산 집계와 업종별 최근 5거래일 합산 수급의 기준일·구성종목 일치 검증이 필요하다. 합산 그래프를 외국인과 기관이 모두 같은 방향으로 매매했다는 근거로 해석하지 않는다. 보존되지 않은 과거 상세 값을 있다고 가정하지 않는다. 수집 유니버스는 시총 상위 300개와 지정 테마이며 전체 시장 통계로 표현하지 않는다.

현재 HTML은 가상 데이터로 만든 화면 미리보기다. 뉴스나 종목 추천을 새로 생성하지 않았으며, 운영 보고서 레이아웃 변경·배포·Notion 재게시는 하지 않았다. 요약 분야 선택 기준, 축 범위, 색상과 세부 여백은 미리보기 구현 선택이며 사용자 확정값으로 간주하지 않는다.

## 2026-09-26 구현

사용자가 진행을 승인해 market_flow.py와 실제 daily_archive 본문 조립에 연결했다. 시장 흐름 → 종합 추천 토글 → 전체 종목 자료 토글 순서다. 원문 내부 토글·표·이미지는 보존한다. 종목 선정은 변경하지 않는다.

자료 흐름은 KIS 투자자 API 원응답 → 수급 CSV의 flow_daily_json → 같은 종목의 수정주가 일봉 날짜 대조 → latest_sector_close.csv의 market_flow_json → 보고서다. 기존 날짜 없는 수급 문자열은 사용하지 않는다. 백만원을 100으로 나누어 억원으로 표시하며 외국인과 기관을 합산한다. 원응답 누락/비수치/날짜 중복은 유효한 0으로 바꾸지 않는다. 5일 모두 모든 구성종목의 날짜가 맞아야 업종 수급 그래프를 만든다. 원문 종목별 이력과 집계시각도 JSON에 보존한다.

구현 기본값은 최대 두 분야다. 최근 5일 평균 수익률이 ±0.3% 밖인 상승·하락 분야가 모두 있으면 각각 가장 큰 변화 하나, 한 방향만 있으면 그 방향의 두 분야를 고른다. 모두 보합이면 이를 명시한다. 순위는 해당 분야의 절대 수급 금액이나 뉴스로 바꾸지 않는다.

상승 확산 문구는 같은 구성종목에서 상승 비율이 직전 5일보다 20%p 이상 높아지고 현재 60% 이상이며 중앙값도 양수인 경우에만 쓴다. 통계적 유의성이나 미래 수익 예측 기준이 아니라 설명을 보수적으로 제한하는 표시 기준이다. 상승·하락 분야의 자금이 서로 이동했다고 추정하지 않는다. 그래프는 업종별 대칭 축이며 축 크기가 서로 다름을 표시한다.

9월 23일 301개 종목을 9월 26일 읽기 전용으로 재조회했다. 업종 28개의 5일 수익률은 기존 마감 CSV와 일치했다. 27개 업종 수급이 완결되었으며 일부 수급이 빠진 화학은 그래프 생성 불가로 표시한다. 당시 수급 응답이 보존돼 있지 않아 9월 26일 재조회임을 명시한다. 기존 운영 CSV와 추천 신호는 이 사후 조회로 덮어쓰지 않는다.
