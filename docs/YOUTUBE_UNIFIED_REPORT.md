# 유튜브 통합 레포트 운영

2026-09-20 사용자 확정. 적용일은 2026-09-21 KST.

프롬프트 정본은 `prompts/youtube_investment_trends.md`다. 전체 요약 3~5줄,
핵심 흐름 3~5개, 마지막 “그래서 한마디로?” 2~3문장으로 구성한다.
근거·원인·기업이 언급된 이유·의견 차이·사업 진행 단계를 설명한다.
약 1,500자 시안의 약 1.5배를 기준으로 하고 이전 날짜 보고서 길이에 배수를 적용하지 않는다.
개별 출처 링크, 영상별 나열, 채널별 토글, 표를 생성하지 않는다.

## 실행 경로

GitHub Actions의 `youtube_report.py`는 기존 영상 분석을 캐시에 저장한다.
9/21부터 영상별 노션 보고서 블록 생성/업로드를 중단한다. 기존 JSON 소비자는 유지한다.

노트북의 기존 `com.vinicius.daily-archive` 감시자가 당일 자료를 동기화한다.
유튜브 입력이 아직 없으면 생성 시도를 소비하지 않고 기다린다.
`daily_archive.collect`가 `youtube_digest.generate`를 통해 그날 글을 한 번 만든다.
대시보드 유튜브 슬롯에 게시한 원문을 다시 읽고, 종합추천 입력과 일일 Report 사본에 사용한다.
휴장일 별도 유튜브 LLM 브리핑은 생성하지 않는다. 새 스케줄/서비스는 추가하지 않는다.

## 비용과 실패

거래일은 당일 저장 분석본, 휴장일은 당일 포함 최근 3일만 사용한다.
중복 영상 ID를 제거하고 입력 전체가 10만자를 넘으면 자동 분할/추가 호출 없이 실패한다.
gpt-5.4-mini low, 응답 상한 6,000토큰, 호출당 120초, SDK 재시도 0회.
프롬프트·입력·모델 해시가 같으면 비공개 캐시를 재사용한다.
실패/결과 불명 호출은 자동 재요청하지 않는다. 노션 재게시에는 캐시된 결과를 사용한다.
생성 실패는 기존 아카이브 상태와 대시보드 경고에 표시한다.

입력/생성/사용량 감사 기록은 `.recommendation_audits/youtube-digest-*`다.
비공개 입력과 실계좌 정보는 저장소에 게시하지 않는다.

## 검증

`test_youtube_digest`는 날짜·중복 제거·입력 상한·캐시·실패 시 재호출 방지·노션 대조·
휴장일 중복 생성 방지·수집기의 채널별 업로드 중단을 격리 검증한다.
`test_recommendation_end_to_end`는 실제 내부 함수와 가짜 외부 응답으로
감시자 → 통합 글 → 종합추천 → 일일 페이지 → 게시 검증 경로를 검사한다.
검증에서 실제 모델 호출, 샘플 생성, 실제 노션 쓰기, 주문 실행은 하지 않는다.
